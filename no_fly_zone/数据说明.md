## 数据概述

本文件夹包含洛杉矶地区的无人机禁飞区数据，共 **32 个** 禁飞区域。禁飞区数据涵盖以下类型：

- 管制空域（Controlled Airspace）
- 机场周边区域
- 其他限制飞行区域

**坐标系**: WGS84 (EPSG:4326)  
**覆盖范围**: 洛杉矶地区  
**数据格式**: GeoJSON、Shapefile、CSV

## 各文件详细说明

### 1. 无人机禁飞区_CGS_WGS84.geojson

**说明**: 禁飞区数据的完整 GeoJSON 格式文件，包含 32 个禁飞区域的几何边界和完整属性信息。

**用途**:
- Web 端三维地图直接加载显示禁飞区范围
- 与建筑数据进行空间叠加分析
- 无人机路径规划时判断是否在禁飞区内

**包含字段**: OBJECTID、bid、zone_id、zone_name、restrict、note、flight_cei、height_met、Area

---

### 2. 无人机禁飞区_CGS_WGS84.shp（及配套文件）

**说明**: Shapefile 格式的禁飞区数据，包含 7 个配套文件，必须同时存在才能正常使用。

**来源**: 由 GeoJSON 数据转换生成，或直接在 ArcGIS Pro 中编辑维护。

**额外字段**: 除 GeoJSON 中的字段外，Shapefile 还包含以下 ArcGIS 自动计算的字段：
- `SHAPE_Leng`: 禁飞区边界长度（以 WGS1984 坐标系的度为单位）
- `SHAPE_Area`: 禁飞区面积（以 WGS1984 坐标系的度²为单位）

**重要提示**: `SHAPE_Leng` 和 `SHAPE_Area` 是以 WGS1984 坐标系（度为单位）自动计算的，其数值单位为度（°）和度²，**不具有实际物理意义**。

---

### 3. 无人机禁飞区_CGS_WGS84.csv

**说明**: 禁飞区属性数据表，由 `无人机禁飞区_CGS_WGS84.shp` 的属性表导出，不包含几何数据。

**用途**:
- 纯属性数据分析
- 与其他表格数据进行合并分析
- 快速查阅禁飞区信息，无需加载地图

## 字段说明

### GeoJSON 属性字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `OBJECTID` | Integer | 原始数据标识符 |
| `bid` | Integer | 禁飞区唯一标识符（从 1 开始递增） |
| `zone_id` | String | 禁飞区编码，如 `D_BUR003` |
| `zone_name` | String | 禁飞区名称，如 `Class C - BUR` |
| `restrict` | String | 限制类型，如 `Controlled Airspace`（管制空域） |
| `note` | String | 详细说明和飞行要求 |
| `flight_cei` | Integer | 飞行限制等级 |
| `height_met` | Integer | 高度限制（米），0 表示完全禁飞 |
| `Area` | Float | **禁飞区面积（单位：平方千米 km²）** |

### Shapefile / CSV 属性字段

| 字段名 | 类型 | 说明 | 对应 GeoJSON 字段 |
|--------|------|------|-------------------|
| `OBJECTID` | Integer | 原始标识符 | `OBJECTID` |
| `BID` | Integer | 唯一标识 | `bid` |
| `ZONE_ID` | String | 禁飞区编码 | `zone_id` |
| `ZONE_NAME` | String | 禁飞区名称 | `zone_name` |
| `RESTRICT` | String | 限制类型 | `restrict` |
| `NOTE` | String | 详细说明 | `note` |
| `FLIGHT_CEI` | Integer | 飞行限制等级 | `flight_cei` |
| `HEIGHT_MET` | Integer | 高度限制 | `height_met` |
| `AREA` | Float | 面积（km²） | `Area` |

### 面积字段特别说明

| 字段名 | 坐标系 | 单位 | 是否推荐使用 |
|--------|--------|------|-------------|
| `Area` / `AREA` | CGS_WGS_1984（等面积投影） | **平方千米（km²）** | ✅ **推荐使用** |
| `SHAPE_Area` | WGS1984（地理坐标系） | 度²（°²） | ❌ 不推荐 |
| `SHAPE_Leng` | WGS1984（地理坐标系） | 度（°） | ❌ 不推荐 |

**重要提示**:
- `Area` 字段是以 **CGS_WGS_1984** 等面积投影坐标系计算得出的面积，单位为 **平方千米（km²）**，可直接用于面积比较和分析
- `SHAPE_Area` 和 `SHAPE_Leng` 是 ArcGIS 以 **WGS1984 地理坐标系** 自动计算的，单位为度和度²，**不具有实际物理长度/面积意义，请勿用于面积分析**
- **如需引用禁飞区面积，请以 `Area` 字段为准**

## 数据格式说明

### GeoJSON vs Shapefile vs CSV

| 特性 | GeoJSON | Shapefile | CSV |
|------|---------|-----------|-----|
| 几何数据 | ✅ 包含 | ✅ 包含 | ❌ 不包含 |
| Web 支持 | ✅ 原生支持 | ❌ 需转换 | ❌ 需关联 |
| 文件数量 | 单个文件 | 多个配套文件 | 单个文件 |
| 适用场景 | Web 地图 | 桌面 GIS | 纯属性分析 |

## 注意事项

1. **面积字段选择**: 禁飞区面积以 `Area` 字段为准，单位为平方千米（km²）
2. **坐标系**: 所有数据使用 WGS84 (EPSG:4326)
3. **Shapefile 配套文件**: 使用 `.shp` 时必须确保所有 7 个配套文件在同一目录下
4. **禁飞区数量**: 共 32 个禁飞区域
5. **高度限制**: `height_met = 0` 表示该禁飞区完全禁止无人机飞行
