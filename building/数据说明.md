## 数据处理流程

本数据集的数据处理遵循以下流程，每一步都生成了对应的文件：

```
la_023012311.json（微软原始数据）
    ↓ 裁剪至研究区域
la_clipped.geojson
    ↓ 计算建筑占地面积
la_clipped_with_area.geojson
    ↓ 对缺失高度进行空间插值填充
la_height_filled.geojson
    ↓ 新增建筑唯一标识字段 bid
LA_building.geojson
    ↓ 转换为 Shapefile 格式
LA_building.shp
    ↓ 导出属性表
LA_building.csv
```

## 各文件详细说明

### 1. la_clipped.geojson

**数据来源**: 微软 GlobalMLBuildingFootprints（原始文件 `la_023012311.json`）

**处理步骤**:
- 使用 ArcGIS Pro 将原始数据裁剪至洛杉矶市中心研究区域
- 保留研究区域内所有建筑轮廓

**包含字段**:
- `height`: 建筑高度（米），部分为 -1 表示无数据
- `confidence`: 轮廓识别置信度（0~1），-1 表示未知

**说明**: 该文件是从原始数据中裁剪出的研究区域子集，不包含面积字段，高度字段中存在缺失值。

---

### 2. la_clipped_with_area.geojson

**数据来源**: 由 `la_clipped.geojson` 衍生

**处理步骤**:
- 在 `la_clipped.geojson` 基础上，使用 Python 脚本计算每个建筑的占地面积
- 使用 shapely 库读取多边形坐标并计算面积
- 面积单位：平方米（m²）

**新增字段**:
- `area_m2`: 建筑占地面积精确值（Float，单位：m²）
- `area_m2_rounded`: 建筑占地面积四舍五入值（Integer，单位：m²）

**说明**: 该文件在裁剪数据基础上增加了面积字段，但仍保留原始高度数据，其中 8,155 个建筑的高度值为 -1（缺失）。

---

### 3. la_height_filled.geojson

**数据来源**: 由 `la_clipped_with_area.geojson` 衍生

**处理步骤**:
- 识别所有 `height = -1` 的建筑（共 8,155 个）
- 使用空间插值方法：以每个缺失高度建筑为中心，搜索邻近网格（约 2km 范围）内的有效高度建筑
- 取邻近建筑高度的**中位数**作为估算值，赋值给缺失建筑
- 部分建筑添加 `height_filled: true` 标记，表示高度为估算值

**字段说明**:
- `height`: 建筑高度（米），缺失值已填充为估算值
- `height_filled`: 布尔标记，`true` 表示该高度为空间插值估算值；无此字段表示原始高度数据
- `confidence`: 轮廓识别置信度
- `area_m2`: 建筑占地面积
- `area_m2_rounded`: 面积四舍五入值

**数据统计**:
| 指标 | 数值 |
|------|------|
| 总建筑数 | 76,634 |
| 原始高度数据 | 68,479 (89.4%) |
| 填充高度数据 | 8,155 (10.6%) |
| 高度范围 | 0.00 ~ 34.89 m |
| 平均高度 | 4.51 m |
| 中位数 | 4.08 m |

---

### 4. LA_building.geojson

**数据来源**: 由 `la_height_filled.geojson` 衍生

**处理步骤**:
- 在 `la_height_filled.geojson` 基础上新增 `bid`（Building ID）字段
- `bid` 为每个建筑分配唯一整数标识，从 1 开始递增
- 该字段可用于建筑识别、属性关联、数据库主键等

**新增字段**:
- `bid`: 建筑唯一标识符（Integer，从 1 开始递增）

**说明**: 该文件为最终版本的 GeoJSON 数据，包含完整的几何信息、高度数据、面积数据和唯一标识，可直接用于三维地图可视化。

---

### 5. LA_building.shp（及配套文件）

**数据来源**: 由 `LA_building.geojson` 转换

**处理步骤**:
- 使用 ArcGIS Pro 或 geopandas 将 `LA_building.geojson` 转换为 Shapefile 格式
- Shapefile 包含 7 个配套文件，必须同时存在才能正常使用

**配套文件说明**:
| 后缀 | 说明 |
|------|------|
| `.shp` | 主文件，存储几何图形数据 |
| `.shx` | 索引文件，存储图形位置索引 |
| `.dbf` | 属性表文件，存储属性数据 |
| `.prj` | 坐标系定义文件 |
| `.cpg` | 字符编码声明 |
| `.sbn` / `.sbx` | 空间索引文件（可选但建议保留） |

**说明**: Shapefile 是 GIS 行业标准的矢量数据格式，适合在桌面 GIS 软件（如 ArcGIS Pro、QGIS）中使用。

---

### 6. LA_building.csv

**数据来源**: 由 `LA_building.shp` 导出

**处理步骤**:
- 使用 ArcGIS Pro 导出 `LA_building.shp` 的属性表为 CSV 格式
- 包含所有属性字段，不含几何数据
- `schema.ini` 文件用于定义 CSV 各字段的数据类型

**包含字段**:
- `bid`: 建筑唯一标识
- `HEIGHT`: 建筑高度
- `CONFIDENCE`: 置信度
- `AREA_M2`: 面积
- `AREA_M2_R`: 面积四舍五入值
- `HEIGHT_FIL`: 高度填充标记（1=估算，0=原始）

**说明**: CSV 文件仅包含属性数据，适合用于数据分析、统计计算或与几何数据分离的场景。

## 字段说明

### GeoJSON 属性字段

| 字段名 | 类型 | 单位 | 说明 |
|--------|------|------|------|
| `bid` | Integer | - | 建筑唯一标识符 |
| `height` | Float | 米 | 建筑高度 |
| `confidence` | Float | - | 轮廓识别置信度 (0~1)，-1 表示未知 |
| `area_m2` | Float | m² | 建筑占地面积精确值 |
| `area_m2_rounded` | Integer | m² | 面积四舍五入值 |
| `height_filled` | Boolean | - | true = 高度为估算填充值 |

### Shapefile / CSV 属性字段

| 字段名 | 类型 | 说明 | 对应 GeoJSON 字段 |
|--------|------|------|-------------------|
| `BID` | Integer | 建筑唯一标识 | `bid` |
| `HEIGHT` | Float | 建筑高度（米） | `height` |
| `CONFIDENCE` | Float | 置信度 | `confidence` |
| `AREA_M2` | Float | 面积（m²） | `area_m2` |
| `AREA_M2_R` | Integer | 面积四舍五入 | `area_m2_rounded` |
| `HEIGHT_FIL` | Integer | 填充标记 | `height_filled` |

**字段名截断说明**: Shapefile 格式限制字段名最多 10 个字符，因此部分字段名被截断：
- `area_m2_rounded` → `AREA_M2_R`
- `height_filled` → `HEIGHT_FIL`

## 数据格式说明

### GeoJSON vs Shapefile

| 特性 | GeoJSON | Shapefile |
|------|---------|-----------|
| Web 支持 | 原生支持 | 需转换为 GeoJSON |
| 文件数量 | 单个文件 | 多个配套文件 |
| 字段名长度 | 无限制 | 最多 10 个字符 |
| 布尔类型 | 支持 | 不支持（转为 0/1） |
| 适用场景 | Web 端三维地图 | 桌面 GIS 软件 |

### 推荐使用场景

| 场景 | 推荐格式 |
|------|----------|
| Web 三维地图 | GeoJSON |
| ArcGIS Pro / QGIS | Shapefile |
| Python 数据分析 | GeoJSON / Shapefile |
| 纯属性数据分析 | CSV |

## 使用建议

### Web 三维地图（Mapbox GL JS）

```javascript
map.addLayer({
  id: 'buildings',
  type: 'fill-extrusion',
  source: {
    type: 'geojson',
    data: 'LA_building.geojson'
  },
  paint: {
    'fill-extrusion-color': [
      'case',
      ['==', ['get', 'height_filled'], true], '#FF6B6B',  // 估算值红色
      '#888888'  // 原始值灰色
    ],
    'fill-extrusion-height': ['get', 'height'],
    'fill-extrusion-opacity': 0.8
  }
});
```

### Python 数据处理

```python
import geopandas as gpd

# 读取 GeoJSON
gdf = gpd.read_file('LA_building.geojson')

# 读取 Shapefile
gdf = gpd.read_file('LA_building.shp')

# 筛选估算高度建筑
filled_buildings = gdf[gdf['height_filled'] == True]

# 保存为 Shapefile
gdf.to_file('output.shp', driver='ESRI Shapefile')
```

## 注意事项

1. **坐标系**: 所有数据使用 WGS84 (EPSG:4326)
2. **高度估算**: 8,155 个建筑（10.6%）的高度为空间插值估算值，精度取决于邻近建筑分布
3. **Shapefile 限制**: 字段名被截断为 10 个字符，需注意字段映射关系
4. **数据更新**: 原始数据来源于微软 GlobalMLBuildingFootprints（2024年），可能存在误差
5. **配套文件**: 使用 Shapefile 时必须确保 7 个配套文件在同一目录下
