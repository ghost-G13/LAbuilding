# LA建筑三维数据 · 字段说明

## 概述

本文件为洛杉矶市中心裁剪区域的建筑三维数据，包含建筑轮廓几何信息及高度属性。所有无高度数据的建筑已通过空间插值方法填充。

- **数据文件**: `la_height_filled.geojson`
- **建筑数量**: 76,634 个
- **坐标系**: WGS84 (EPSG:4326)
- **数据来源**: 微软 GlobalMLBuildingFootprints

## 属性字段说明

### 核心字段

| 字段名 | 类型 | 单位 | 说明 | 示例值 |
|--------|------|------|------|--------|
| `height` | Float | 米 | 建筑高度。原始高度或通过空间插值填充 | `3.37`, `4.30`, `7.13` |
| `confidence` | Float | - | 建筑轮廓识别置信度 (0~1)，-1表示未知 | `0.96`, `1.0`, `-1.0` |
| `area_m2` | Float | 平方米 | 建筑占地面积（精确值） | `100.14`, `289.85` |
| `area_m2_rounded` | Integer | 平方米 | 建筑占地面积（四舍五入） | `100`, `290` |

### 填充标记字段

| 字段名 (GeoJSON) | 字段名 (Shapefile) | 类型 | 说明 |
|-----------------|-------------------|------|------|
| `height_filled` | `height_fil` | Boolean / Integer | GeoJSON中`true`表示高度为估算值；转换为Shapefile后，`1`表示估算值，`0`表示原始高度 |

> **Shapefile 转换说明**:
> - GeoJSON 的 `height_filled` 字段在转换为 Shapefile 时会被截断为 `height_fil`（Shapefile 字段名最多10个字符）
> - 布尔类型 `true` 会转换为整数 `1`
> - 无此字段的建筑在属性表中显示为 `0`，表示原始高度数据

## GeoJSON 与 Shapefile 选择建议

### 用于三维地图 Web 端

**推荐使用 GeoJSON**

| 维度 | GeoJSON | Shapefile |
|------|---------|-----------|
| **Web 兼容性** | ✅ 原生支持，无需转换 | ❌ 需要转换为 GeoJSON/TileJSON |
| **加载方式** | ✅ 直接通过 AJAX 加载 | ❌ 需要后端服务 |
| **体积** | ⚠️ 较大（纯文本） | ✅ 二进制压缩，体积小 |
| **跨域** | ✅ 无限制 | ❌ 需要配置 CORS |
| **可视化库支持** | ✅ Mapbox GL JS, Leaflet, Cesium 等原生支持 | ❌ 需要转换 |

### 使用建议

1. **直接加载（数据量较小）**:
   - 数据量: < 10万条
   - 方式: 直接加载 GeoJSON 文件

2. **切片服务（数据量大）**:
   - 数据量: > 10万条
   - 方式: 使用 `tippecanoe` 生成矢量瓦片
   ```bash
   tippecanoe -o buildings.mbtiles la_height_filled.geojson
   ```

3. **简化处理**:
   - 对建筑轮廓进行简化，减少顶点数量
   - 使用 TopologyJSON 格式压缩

### 三维可视化方案

| 方案 | 说明 |
|------|------|
| **Mapbox GL JS** | 使用 `fill-extrusion` 绘制三维建筑 |
| **CesiumJS** | 使用 `PolygonGeometry` + `extrudedHeight` |
| **Three.js** | 自定义几何体，自由度最高 |

### Mapbox GL JS 示例配置

```javascript
map.addLayer({
  id: 'buildings',
  type: 'fill-extrusion',
  source: {
    type: 'geojson',
    data: 'la_height_filled.geojson'
  },
  paint: {
    'fill-extrusion-color': '#888888',
    'fill-extrusion-height': ['get', 'height'],
    'fill-extrusion-base': 0,
    'fill-extrusion-opacity': 0.8
  }
});
```

### Shapefile 适用场景

- 桌面 GIS 软件分析（ArcGIS, QGIS）
- 需要属性表操作
- 与其他矢量数据合并处理

如需转换为 Shapefile：

```python
import geopandas as gpd
gdf = gpd.read_file('la_height_filled.geojson')
gdf.to_file('la_buildings.shp', driver='ESRI Shapefile')
```

## 注意事项

1. **高度单位**: 所有高度值单位为米
2. **填充标记**: `height_filled: true` 的建筑高度为估算值，精度取决于周边建筑分布
3. **坐标系**: 需确保地图底图使用相同坐标系（WGS84/EPSG:4326）
4. **数据量**: 76,634 条数据建议使用矢量瓦片或按需加载策略
