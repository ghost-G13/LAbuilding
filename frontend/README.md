# 城市低空三维白模可视化与分析系统

## 项目概述

本系统是一个基于 Vue 3 + Cesium 的城市低空三维可视化与分析平台，提供建筑三维白模展示、起降点分析、航线碰撞预警等功能，并支持多语言切换、深色主题和字号调整。

## 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | 3.x | 前端框架 |
| Vite | 8.x | 构建工具 |
| Cesium | 1.x | 三维地球可视化引擎 |
| Vue Router | 4.x | 路由管理 |

## 功能特性

### 1. 建筑三维可视化

- 基于 Cesium 的三维地球展示
- 建筑高度分级着色（0-5m、5-10m、10-15m、15-20m、20-25m、25-30m、>30m）
- 鼠标交互：左键旋转、滚轮缩放、右键平移
- 左侧图例显示建筑高度分级

### 2. 起降点分析

- 飞行高度范围筛选（最小值/最大值）
- 建筑面积范围筛选（最小值/最大值）
- 筛选结果统计显示
- 导出分析结果（CSV格式）

### 3. 航线碰撞预警

- 绘制飞行范围
- 设置飞行高度
- 检测与禁飞区的碰撞
- 实时状态显示（合规/警告/禁飞区）

### 4. 用户认证

- 用户登录/注册
- 验证码验证
- 密码强度检测
- 记住账号功能

### 5. 多语言支持

系统支持中文和英文两种语言，切换时所有界面文字同步变更：

- 顶部导航栏
- 右侧功能面板（起降点分析、航线碰撞预警）
- 登录/注册模态框
- 设置弹窗
- 图例和底部提示
- 经纬度范围显示（中文：E/N，英文：Lon/Lat）
- 面积单位（中文：公顷，英文：ha）

**注意**：禁飞区点选标识中的英文标注保持不变。

### 6. 深色主题

深色主题仅影响 UI 控件，不改变地图底图和建筑色彩：

**顶部导航栏**
- 底色：炭黑色渐变
- 文字/图标：浅灰白色
- 设置/admin按钮：深灰底色 + 浅灰边框 + 浅白文字

**右侧功能面板**
- 面板底色：深炭灰色
- 边框：低对比度浅灰细线
- 标题文字：亮白色
- 正文说明：浅灰色
- 橙色提示：降低饱和度
- 输入框：深灰底色 + 浅灰边框
- 普通按钮：深灰底色 + 浅灰边框 + 浅白文字
- 绘制按钮：暗金/暗黄色底色

**底部状态栏**
- 背景：半透明深黑色遮罩
- 文字：浅灰白色

**锁色不变部分**
- 地图底图所有元素
- 建筑专题填色
- 左侧图例色块 + 文字

### 7. 字号调整

系统支持三种字号：

| 字号 | 说明 |
|------|------|
| 小号 | 适合高分辨率屏幕 |
| 中号 | 默认大小 |
| 大号 | 适合大屏展示 |

字号变化影响：
- 系统名称
- 导航栏按钮
- 右侧功能面板文字
- 图例文字
- 底部提示文字

## 快速开始

### 安装依赖

```bash
cd frontend
npm install
```

### 开发模式

```bash
npm run dev
```

### 生产构建

```bash
npm run build
```

## 配置说明

### 环境变量

在 `frontend` 目录下创建 `.env` 文件：

```env
VITE_API_BASE_URL=http://localhost:3000/api
```

## 使用说明

### 操作指南

1. **旋转视角**：鼠标左键拖拽
2. **缩放**：滚轮
3. **平移**：右键拖拽

### 功能面板

- **起降点分析**：设置高度和面积范围，点击筛选查看结果
- **航线碰撞预警**：点击"绘制范围"按钮，在地图上绘制多边形，设置飞行高度后检测碰撞

### 设置

点击右上角设置按钮，可调整：
- 语言：中文/英文
- 主题：浅色/深色
- 字号：小/中/大
